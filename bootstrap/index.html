03 / Public API

Data beyond the browser.

The Open-Meteo API returns forecast data in JSON. JavaScript extracts the useful values and updates this page without reloading it. No API key is required.

1. fetch() requests the forecast.
2. JavaScript reads and checks the JSON.
3. The page displays temperatures and rain probability.

The button is disabled while loading. A clear status message appears if the response fails or returns unexpected data, so the page remains usable.
